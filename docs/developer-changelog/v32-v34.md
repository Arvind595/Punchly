## v33 · Undo, full-period analytics, and timer controls

**Evidence.** Dedicated v33 release commit. [`3fe903a`](https://github.com/Arvind595/Punchly/commit/3fe903a9b39307d6cf8ab99fbc1f308d4206cf4c) · [Diff 6a9686b → 3fe903a](https://github.com/Arvind595/Punchly/compare/6a9686bdb8a5c2305445fb5ea71fcb6fcaf83721...3fe903a9b39307d6cf8ab99fbc1f308d4206cf4c)

### Punch lifecycle and undo

- The app snapshots the daily draft and matching History entry before committing a punch. Guided checkout can write both. A 12-second toast offers Undo and a 600 ms guard suppresses rapid repeated punch actions. Undo can reopen an accidental checkout. [Guided write](https://github.com/Arvind595/Punchly/blob/3fe903a9b39307d6cf8ab99fbc1f308d4206cf4c/js/app.js#L619) · [Undo UI](https://github.com/Arvind595/Punchly/blob/3fe903a9b39307d6cf8ab99fbc1f308d4206cf4c/js/app.js#L1474) · [Rapid-action guard](https://github.com/Arvind595/Punchly/blob/3fe903a9b39307d6cf8ab99fbc1f308d4206cf4c/js/guided-punch.js#L114)
- `Storage.undoPunch` compares the current saved state with the state captured immediately after the punch before restoring the previous date-scoped values. A newer edit blocks undo. The write path attempts rollback if a later key write fails, and other dates stay independent of the operation. [Snapshot](https://github.com/Arvind595/Punchly/blob/3fe903a9b39307d6cf8ab99fbc1f308d4206cf4c/js/storage.js#L287) · [Compare and restore](https://github.com/Arvind595/Punchly/blob/3fe903a9b39307d6cf8ab99fbc1f308d4206cf4c/js/storage.js#L294) · [Undo regression](https://github.com/Arvind595/Punchly/blob/3fe903a9b39307d6cf8ab99fbc1f308d4206cf4c/tests/storage-recovery.test.mjs#L27)

### Desktop mini timer, Settings, and report changes

- **Timer.** `timing` translates the measured shift into working, lunch, target reached, overtime, completed, not started, day off, or a punch validation state. After reaching the target, the counter displays worked overtime. The existing open interval and panel survive a change to Always on top. Turning it on during a user gesture can request a floating window again, and turning it off moves the timer back into the app. Opacity and app theme apply to the timer content. [State and counter](https://github.com/Arvind595/Punchly/blob/3fe903a9b39307d6cf8ab99fbc1f308d4206cf4c/js/mini-timer.js#L8) · [Window transition](https://github.com/Arvind595/Punchly/blob/3fe903a9b39307d6cf8ab99fbc1f308d4206cf4c/js/mini-timer.js#L134) · [`mini-timer.test.mjs`](https://github.com/Arvind595/Punchly/blob/3fe903a9b39307d6cf8ab99fbc1f308d4206cf4c/tests/mini-timer.test.mjs)

The weekly in-app backup reminder uses the latest successful export and reminder timestamps, and only appears when there is data to back up. ## v34 · Custom date ranges and workflow repair

- **Input and comparison.** The Statistics selector adds Custom dates with From, To, and Apply dates.
