## v26 · Minimum lunch deduction

**Evidence.** The v29 snapshot retains the v26 note. Compare the entire v25-to-v29 change for code introduced across v26–v29. [Archived v26 note](https://github.com/Arvind595/Punchly/blob/4192dfe255e335c2d8316414035430ca5a19d876/index.html#L413) · [Diff 8d5b2fc → 4192dfe](https://github.com/Arvind595/Punchly/compare/8d5b2fc4a775f35056a19b742e716e66c61d7ac3...4192dfe255e335c2d8316414035430ca5a19d876)

- **Calculation.** With the option enabled, a full day deducts the larger of the configured lunch limit and the recorded lunch. A skipped lunch still deducts the minimum. During a shift, the calculation reserves the unused part of the minimum, so worked time and projected checkout use the same policy. Half days have no lunch interval to deduct. [Calculation](https://github.com/Arvind595/Punchly/blob/4192dfe255e335c2d8316414035430ca5a19d876/js/shift.js#L97)
- **Compatibility.** `lunchPolicy` chooses the saved policy for a completed record. A missing historical minimum flag uses the older calculation. New and unfinished shifts read current preferences. The saved daily record distinguishes actual lunch, deducted lunch and the policy used for the calculation. [Effective policy](https://github.com/Arvind595/Punchly/blob/4192dfe255e335c2d8316414035430ca5a19d876/js/app.js#L598) · [Record fields](https://github.com/Arvind595/Punchly/blob/4192dfe255e335c2d8316414035430ca5a19d876/js/app.js#L1041)
- **Verification.** The regression suite covers short and extended breaks, skipped lunch, live estimates, overnight shifts, zero limits and legacy settings. The exports carry actual and deducted lunch as separate values. [`lunch-policy.test.mjs`](https://github.com/Arvind595/Punchly/blob/4192dfe255e335c2d8316414035430ca5a19d876/tests/lunch-policy.test.mjs) · [Report field](https://github.com/Arvind595/Punchly/blob/4192dfe255e335c2d8316414035430ca5a19d876/js/export.js#L3)

## v31 · Backup validation, rollback, and export round trips

**Evidence.** v31 release marker and archived note. [`c9c0992`](https://github.com/Arvind595/Punchly/commit/c9c099231c51710f002f716d5f64fa2bce58c91f) · [Archived v31 note](https://github.com/Arvind595/Punchly/blob/c9c099231c51710f002f716d5f64fa2bce58c91f/index.html#L417)

1. `validateBackup` checks format and schema version, valid calendar dates and times, field shapes, supported modes, audit entries, and duplicate daily dates or record IDs. The restore dialog reports overlaps between existing and incoming daily dates. A malformed file fails before record writes. [Validation](https://github.com/Arvind595/Punchly/blob/c9c099231c51710f002f716d5f64fa2bce58c91f/js/storage.js#L202) · [Overlap preview](https://github.com/Arvind595/Punchly/blob/c9c099231c51710f002f716d5f64fa2bce58c91f/js/storage.js#L390) · [Restore UI](https://github.com/Arvind595/Punchly/blob/c9c099231c51710f002f716d5f64fa2bce58c91f/js/export.js#L403)
2. `beginRecovery` stores a temporary copy of the original raw browser values before either restore mode writes. Merge keeps existing daily dates, weekly IDs, overlapping drafts and preferences. Replace restores data and preferences from the backup. If writing fails, the app attempts rollback, and failed rollback leaves a recovery copy available. Storage quota failures have distinct messages. [Recovery snapshot](https://github.com/Arvind595/Punchly/blob/c9c099231c51710f002f716d5f64fa2bce58c91f/js/storage.js#L263) · [Restore transaction](https://github.com/Arvind595/Punchly/blob/c9c099231c51710f002f716d5f64fa2bce58c91f/js/storage.js#L355) · [Recover from a saved copy](https://github.com/Arvind595/Punchly/blob/c9c099231c51710f002f716d5f64fa2bce58c91f/js/storage.js#L281)
3. Settings reads diagnostics and shows recovery tools when stored data is damaged. The last-backup timestamp records a validated backup export being handed to the browser for download. The backup format remains `punchly-backup` version 1 and recovery data uses `punchly-recovery` version 1. [Storage diagnostics](https://github.com/Arvind595/Punchly/blob/c9c099231c51710f002f716d5f64fa2bce58c91f/js/storage.js#L287) · [Download and timestamp](https://github.com/Arvind595/Punchly/blob/c9c099231c51710f002f716d5f64fa2bce58c91f/js/export.js#L370) · [Recovery format](https://github.com/Arvind595/Punchly/blob/c9c099231c51710f002f716d5f64fa2bce58c91f/js/storage.js#L259)
4. Tests exercise backup recovery, restore and report round trips, permission changes, reminder deduplication, and timer countdown. Appearance's `drawThemeTile` uses inline SVG color strips sized by CSS. [`storage-recovery.test.mjs`](https://github.com/Arvind595/Punchly/blob/c9c099231c51710f002f716d5f64fa2bce58c91f/tests/storage-recovery.test.mjs) · [`export-roundtrip.test.mjs`](https://github.com/Arvind595/Punchly/blob/c9c099231c51710f002f716d5f64fa2bce58c91f/tests/export-roundtrip.test.mjs) · [`reminders.test.mjs`](https://github.com/Arvind595/Punchly/blob/c9c099231c51710f002f716d5f64fa2bce58c91f/tests/reminders.test.mjs) · [Vector theme preview](https://github.com/Arvind595/Punchly/blob/c9c099231c51710f002f716d5f64fa2bce58c91f/js/settings.js#L90)
