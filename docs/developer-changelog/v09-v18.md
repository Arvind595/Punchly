## v11 · When a punch was entered

**Evidence.** The v12 README attributes recorded edit timestamps to v11. The first retained source implementing that behavior is the v12 snapshot. [Historical v11 guidance](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/README.md#L29) · [Audit implementation](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/audit.js#L8)

- The clock value of a punch represents the shift time. The audit event's ISO timestamp represents when the value was entered or edited. The two may be on different days. Date-keyed drafts keep audit information as edits are promoted to saved daily records. [Audit on drafts](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/app.js#L992) · [Audit on saved shifts](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/app.js#L992)
- Audit events record field-level previous and new values. Older records can load without audit fields, and only subsequent edits gain timestamps. Use `Audit.punchedAt` to trace which log event supplies a displayed or exported recording time. [Recorded punch timestamp](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/audit.js#L38) · [Audit validation](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/audit.js#L73)

## v12 · Profile tools, audit presentation, and report metadata

**Evidence.** v12 release marker. [`c9ff671`](https://github.com/Arvind595/Punchly/commit/c9ff67159f10b34eb5105abee0b07f901485a5ce) · [Diff ffc8646 → c9ff671](https://github.com/Arvind595/Punchly/compare/ffc86462836439fcc1faee5b19b71ac55158a9dc...c9ff67159f10b34eb5105abee0b07f901485a5ce)

- **Profile.** Settings adds illustrated avatars and initials. A photo is cropped locally and stored with the profile. `AppTools.connectPhoto` owns crop interaction and `Preferences.applyProfile` applies display preferences. The file signature, upload size and decoded dimensions are checked by later v32 code. [Photo crop](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/app-tools.js#L183) · [Profile rendering](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/settings.js#L70)
- **Delete and reset.** The shared dialog offers a backup. Profile deletion updates preferences, while full reset removes app records and state. A reset marker supports the reload path across tabs. Settings-only export/restore travels separately from the full backup. [Reset and deletion UI](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/app-tools.js#L233) · [Profile deletion](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/storage.js#L161) · [Settings restore](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/storage.js#L136)
- **Audit and exports.** History exposes a change log. Report metadata includes the profile name, release and export time. CSV carries recorded timestamps and serialized changes, Excel has a Change log sheet, PDF renders past changes, and PNG carries structured data. This snapshot precedes v29's user-controlled log inclusion. [Audit presentation](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/audit.js#L55) · [Report metadata](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/export.js#L22) · [PNG metadata](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/export.js#L117)
- **App shell and support.** The new app-tools module owns update checks, dialogs, help and email draft generation. Device details are optional in the support draft. Icons move into a shared bundled Material Symbols helper. [Update checks](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/app-tools.js#L32) · [Help and support](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/app-tools.js#L120) · [Icon rendering](https://github.com/Arvind595/Punchly/blob/c9ff67159f10b34eb5105abee0b07f901485a5ce/js/icons.js#L49)

## v14–v16 · Planned punches, national holidays, and the Week redesign

**Evidence.** The v18 in-app notes describe v14–v16 together. The individual release boundaries are unresolved. [Archived grouped notes](https://github.com/Arvind595/Punchly/blob/73164717076339aa4a8ed71ebfd0ac7b0f1345c5/index.html#L391)

- **Dial.** `planShift` creates planned times, and `paintTimeline` builds SVG arcs and tick marks. Recorded punch markers and the estimated checkout are rendered alongside planned markers. The clip and layout are defined by the corresponding Punch CSS. [Plan](https://github.com/Arvind595/Punchly/blob/73164717076339aa4a8ed71ebfd0ac7b0f1345c5/js/guided-punch.js#L27) · [SVG timeline](https://github.com/Arvind595/Punchly/blob/73164717076339aa4a8ed71ebfd0ac7b0f1345c5/js/guided-punch.js#L45) · [Dial layout](https://github.com/Arvind595/Punchly/blob/73164717076339aa4a8ed71ebfd0ac7b0f1345c5/css/style.css#L318)
- **National holidays.** The calendar adds Republic Day, Independence Day and Gandhi Jayanti. `nationalHoliday` resolves the recurring date, `nationalHolidayDates` enumerates dates inside a range, and `holidayNotes` appends the holiday name if it is missing. [Holiday definitions](https://github.com/Arvind595/Punchly/blob/73164717076339aa4a8ed71ebfd0ac7b0f1345c5/js/shift.js#L5) · [Generated notes](https://github.com/Arvind595/Punchly/blob/73164717076339aa4a8ed71ebfd0ac7b0f1345c5/js/shift.js#L54) · [Derived rows](https://github.com/Arvind595/Punchly/blob/73164717076339aa4a8ed71ebfd0ac7b0f1345c5/js/app.js#L970)
- **Week and archived data.** Week moves to a single editable daily-driven time card. Old manual weekly reports remain readable in History and have an archive renderer. Design changes update the next-action and backup transfer icons. [Daily table](https://github.com/Arvind595/Punchly/blob/73164717076339aa4a8ed71ebfd0ac7b0f1345c5/js/app.js#L557) · [Legacy reports](https://github.com/Arvind595/Punchly/blob/73164717076339aa4a8ed71ebfd0ac7b0f1345c5/js/app.js#L1002) · [Week markup](https://github.com/Arvind595/Punchly/blob/73164717076339aa4a8ed71ebfd0ac7b0f1345c5/index.html#L184)
